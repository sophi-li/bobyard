# Sophia's Bobyard submission 

## Install
Run frontend local build
```
cd bobyard/bobyard-fe
npm install
npm run dev
```

Run backend local server
```
cd bobyard/bobyard-server
npm install
node server.js
```

## Usage
Current functionality
- Render all comments
- Add a comment as "Admin" user
